# 盲区：普通 MLP 学不会算术，只能在训练分布内"近似拟合"

**主题大类**：模型结构 / 表达能力

## 误区

"既然神经网络是通用近似器（Universal Approximation Theorem），那喂大量 `(a, b, op) → result` 的样本，MLP 应该能学会加减乘除。"
—— 由此延伸：训练 loss 一直在下降就以为在"学会算术"。

## 真相

UAT 只保证**在紧致集上、对连续函数、有任意精度近似存在**——它**不保证**：

1. 用梯度下降能找到那个近似（最优化层面）
2. 在训练分布外仍成立（外推层面）
3. 近似误差能逼近 0（实际工程层面 ReLU MLP 永远有量化误差）

对算术任务，这三点都会塌，且**塌得分操作不一样**：

| op | 数学性质 | ReLU MLP 表现 | 外推（超训练分布）|
|---|---|---|---|
| `a + b` | **线性** | 一层 Linear 即可精确表达；MLP 容易拟合到极小误差 | 理论可外推，实际权重含误差，远端会漂 |
| `a - b` | **线性** | 同上 | 同上 |
| `a * b` | **双线性 / 非线性** | **永远只能近似**，训练 loss 卡在某 floor 不下来 | **完全不能外推**——给 `[0, 200]²` 误差爆炸 |
| `a / b` | 在 `b → 0` 处奇异 | 学不会，靠近 0 处误差无界 | 同上 |
| `a ^ b` | 严重非线性 + 值域爆炸 | 学不会；值域 `10^200` 完全主导 MSE | 不可能 |

**关键洞察**：MLP 学的是"数据分布内的几何近似"，不是"算术结构"。它没有"乘法"这个算子；它只能用大量 ReLU 折线在 `[0,100]²` 平面上**拼出 `a*b` 这个曲面的一个补丁**。补丁外面，曲面是什么样它无从得知。

## 工程证据

`001_MathNet.py` 训 20 epoch 后：
- normalized MAE ≈ 6e-4 → 反归一约 **±6**（最大 ±9）
- add/sub 样本误差小（接近 0）；mul 样本误差占主导
- 加大训练量、加深网络只能让 add/sub 趋近 0；**mul 会卡在某个 floor**
- 把测试样本换成 `[0, 200]²`，mul 误差立刻量级跳变（外推失败）

## 学术背景

这是 ML 圈的一个公开问题，DeepMind 2018 年专门提出 **NALU (Neural Arithmetic Logic Units)**（Trask et al.），论文开篇就指出**普通神经网络连恒等函数都外推不了**。后续 NAU/NMU/iNALU 等工作都围绕"显式给网络一个会算术的算子"。

## 怎么真的"会"算术

| 思路 | 怎么改 | 副作用 |
|---|---|---|
| **log-空间** | 对正数 `a, b`，输入改成 `(log a, log b)`，输出加 `exp` | mul 立刻线性可学；只对正数有效 |
| **NALU/NMU** | 显式提供 `add` 与 `mul` 两个 cell（NALU 内部就用 log/exp 实现 mul），用 sigmoid 门软选择 | 训练不稳定；后续 iNALU 改进了 |
| **结构归纳偏置** | 让权重接近 0/1（稀疏 + 二值化），逼网络学到"接近真正算术结构"的解 | 训练困难，需要特殊正则 |
| **拆头 + 显式算子** | 每个 op 一个独立子网络，只让它学自己负责的那个 | 工程繁琐，但确定能 work |

## 直观比喻

> MLP 像一个**不懂数学的画师**：你让他画一张 `z = a*b` 的曲面，他能在你给他看过的画框 `[0,100]²` 里**用很多直纸条拼出**一张接近的图；但你把画框扩到 `[0,200]²`，他从没见过那部分，**只能瞎涂**。
>
> 真正"会"乘法的网络（NALU、log-空间），相当于教画师**先理解透视原理**——再大的画框他也能按规则画。

## 一句话记住

> **UAT ≠ 学得会**。MLP 对 add/sub 是"几乎完美"，对 mul 是"训练分布内近似 + 完全不能外推"，对 div/power 是"学不会"。想真学会算术，要么换 log-空间，要么显式给网络配上算术算子（NALU 系列）。
