# 盲区：优化器 / LRScheduler 是有状态的，不是纯函数

**触发场景**：2026-05-07，KongMing 框架 review，看到 Archiver 只存 `model.state_dict()` 不存 optimizer 时问"优化器难道在训练中也有变化，它不就是一个函数…"

## 误区

把"优化器"想成一个**无状态映射** `(param, grad, lr) → new_param`，因此每次 `inc` 重新 `new Adam(...)` 没有问题。

## 真相

主流优化器都带"惯性记忆"，状态随训练演化，是 checkpoint 的**第二份必存数据**。

### Adam 的更新规则

```
m_t     = β1 * m_{t-1} + (1 - β1) * grad           # 一阶矩（动量）
v_t     = β2 * v_{t-1} + (1 - β2) * grad²          # 二阶矩（自适应学习率）
m_hat   = m_t / (1 - β1^t)                         # 偏差修正，依赖 step t
v_hat   = v_t / (1 - β2^t)
param  -= lr * m_hat / (sqrt(v_hat) + eps)
```

下一步走哪取决于**历史梯度的累积**（`m`, `v`），不只是当前 batch。Adam 类似一个带惯性的低通滤波器。

### inc 重启会"抖一下"的原因

只恢复权重、`Optimizer` 重新 new：

- `m`, `v` 全部归零。
- 重启后头几步 `m_hat = grad / (1-β1) ≈ 当前 grad`，方向不稳。
- bias correction 假设 step 从 0 起算，**重新 new 等于撒了个"我从没训过"的谎**——实际权重已经在 loss landscape 深处了。

表现：损失先飙一下，过几十~几百 step 才回到原水平。长跑训练每次 `inc` 都损失一段进度。

## 哪些优化器有状态

| 优化器 | 状态内容 | 必须存？ |
|---|---|---|
| Adam / AdamW / RAdam / Lion | `step`, `exp_avg` (m), `exp_avg_sq` (v) | ✅ |
| SGD with momentum | `momentum_buffer` (velocity) | ✅ |
| RMSprop | `square_avg` | ✅ |
| Adagrad | `sum`（梯度平方累加） | ✅ |
| 纯 SGD（无 momentum） | 无 | ❌ 接近纯函数 |

> 现代训练几乎不用纯 SGD——所以默认认为"优化器一定有状态"是对的。

## LRScheduler 同理

`CosineAnnealingLR`, `StepLR`, `OneCycleLR`, `ReduceLROnPlateau` 等内部维护 `last_epoch` / `_step_count` / `_last_lr`，决定当前 lr。

不恢复状态 → 重启后 lr 回到初始值，warm-up / decay 全部重来。

## 直观比喻

> 优化器像导航：**模型权重是当前位置，优化器状态是当前速度向量和走过多远**。
> 只存位置不存速度，重启 = 在高速路上从静止重新起步——位置没错，但加速过程白费了。

## 在 KongMing 里如何落地

修复见 `docs/KongMing-Review.md` #1。要点：

- `BaseNNModel.StateDictForArchive()` 返回 `{"Model": ..., "BackPropagater": {"Optimizer": ..., "LRScheduler": ...}}`。
- `LoadStateDictFromArchive(loaded)` 检测 dict 还是裸 OrderedDict，向后兼容旧 .pkl。
- 优化器在 `_CreateOptimizer()` 时才 new 出来——**早于 Load 不可能注入**。所以 `BackPropagater` 用 `_PendingState` 缓存，等 `ApplyOptimizer / ApplyLRScheduler` 创建实例后再 `load_state_dict` 灌入。

这个"加载顺序倒置 → pending state 缓存"的小模式以后还会用：**任何"运行时才创建、但加载在前"的对象都需要类似两阶段恢复**。

## 一句话记住

> **保存模型 = 保存权重 + 优化器状态 + scheduler 状态。少一个都是隐性回归。**
